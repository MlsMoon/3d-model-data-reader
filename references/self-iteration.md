# 3D 读取自我迭代

试错不能只留在本轮对话。通过门禁的尝试必须变成正式旗标、口径或用法。

本文件是通用读取/写入协议，不绑定任何游戏工程。禁止写入宿主工程路径、
家具名、关卡名或业务资产名。

## 何时触发

本轮出现以下任一情况，收尾前必须跑升格门禁：

- 执行了 >=3 次 `obj_reader.py` / `fbx_reader.py` / `extract_submeshes.py`
- 同一旗标族失败或改参后重试 >=2 次
- 用临时 Python、手工数 UV、或只对 albedo 颜色阈值完成了本可变成一等旗标的能力

同一旗标族连续失败 2 次后，第三次之前必须重读 `SKILL.md` 或 `--help`，
禁止凭记忆再猜参数。

## 落点（只选一处）

| 落点 | 何时 |
|---|---|
| 正式 CLI 旗标 | 缺稳定动词、结构化输出、失败码或可复用几何统计 |
| `references/` 口径 | 格式陷阱、索引/轴/单位、UV 岛语义 |
| 本 skill `SKILL.md` 用法 | 触发词、检查清单、示例命令 |

不要把同一段知识同时写进脚本注释、reference 和 README。

## 授权

门禁通过后可直接回写本 skill 的 `SKILL.md`、`references/` 和 `scripts/`。
宿主工程 skill、新建独立 skill、或把业务资产名写进本仓，仍需用户确认。

单个 `.py` 仍约 250 行；新能力按职责拆文件，不要把几何解析塞进 CLI 入口。
